    01 · The brief

    What the hackathon is asking for

    The official challenge is “Detecting Fraudulent Links and Websites Used in Cybercrimes and Financial Fraud.” The organisers (Abu Dhabi Police with 42 Abu Dhabi) want technical solutions that find fraudulent links and sites on the open internet, including those that appear in search-engine results and on Maps. The goal is early detection and stronger proactive action against financial fraud.

    The rules that decide everything

    • A working product or MVP. An idea, slide deck or mockup with no real function is disqualified. The organiser repeated this three times.
    • Team of at least 3. Final pitch is in person at 42 Abu Dhabi, Arabic and English together preferred.
    • Submit: project name with 2–4 sentence description (600 chars max), tools used, a repository link, a PPT/PDF deck, and a 1-minute demo video on YouTube Unlisted or Drive.
    • The video must be you explaining. AI-generated video is rejected.

    Timeline (UAE time)

    Kick-offTue 24 Nov · 08:00
    Submission deadlineWed 25 Nov · 08:00
    Elimination roundWed 25 Nov · 10:00
    Finalists presentThu 26 Nov
    AwardsMon 30 Nov

    About 24 hours to build. Prize pool AED 50,000 (split not officially confirmed).

    Where you win. Every competitor posted on the forum is building a reactive checker: the user pastes a link or a screenshot and gets a risk score. Nobody mentioned search results or Maps, even though both are written into the challenge text. RASID is the opposite shape: a proactive hunting console for the police. The investigator types an entity name and watches the system find the fakes, live, in front of the judges.
    Code timing. The organiser has not answered whether coding before kick-off is allowed. Prepare research, data, architecture and the official-domain/phone allowlists now. Write the core code after 08:00 on 24 Nov so the Git commit history proves it was built during the event.
    02 · Why it is needed

    Victims never paste the link into a checker

    Scams live where people search

    Someone searching “pay traffic fine Abu Dhabi” or tapping a Maps listing for “bank customer care” trusts the result because Google showed it. A checker app only helps if the victim is already suspicious, which is exactly when they are not.

    Scams follow the calendar

    Fake F1 tickets before the Grand Prix, fake gifts on National Day, fake Umrah visas before Ramadan, fake Hajj packages before the season. The lookalike domains are registered days or weeks ahead, which gives a window to catch them first.

    Scams speak the victim’s language

    Job and visa fraud targeting workers coming to the UAE is written in Hindi, Urdu, Malayalam, Tamil, Sinhala, Tagalog, Bengali and Nepali, often in Roman script. English-only detection misses most of it.

    One actor, hundreds of sites

    Taking down one domain does little when the same phishing kit runs on 40 more. Police need the cluster, the shared fingerprints and an evidence pack that lets them act against the whole operation.

    How the map UI borrows from the references without copying them

    Arcs mean something different per sensor

    On the Check Point map an arc is attacker → victim country. In RASID, domain arcs run hosting location → the UAE brand being impersonated, and job-scam arcs run the victim’s home city → the UAE, the recruitment corridor the scam promises. The map shows who is being lured, from where.

    Two zoom levels

    World shows infrastructure and corridors. UAE ground zooms to the emirates and shows physical Maps listings (bank “branches”, courier hubs, ticket offices, recruitment centres) as verified or flagged pins.

    Language is a map layer

    Every pin carries the victim language (ML, UR, TL…). The language chips filter the map and the live feed, so an officer can ask “show me everything targeting Malayalam speakers this week.”

    Calendar strip under the pulse

    Like the timeline in your first reference, but with upcoming events and a countdown. Each event is a watchlist with its own lookalike count, so spikes on the pulse line up with the event that caused them.

    04 · The six sensors

    What each one catches, how, and what to build in 24 hours

    SENSOR 1

    Maps Verifier

    مدقق الخرائط

    Catches

    • Fake “customer care 24/7” listings for banks and telcos
    • Courier, ticket-office and recruitment pins that route to scam numbers
    • Real-looking listings whose website is a lookalike domain

    How it works

    1. For each watchlist brand, run Places API Text Search per emirate (“ADCB branch Abu Dhabi”, also in Arabic).
    2. Pull name, phone, website, category, rating count.
    3. Check phone against the brand’s official numbers, website against official domains.
    4. Fetch the listed website and read the phone printed on it: listing ↔ site ↔ registry must all agree.
    5. Index every phone number; one mobile number on several brands’ listings = one actor.

    Red flags it scores

    • A bank or telco “branch” using a mobile number (05x) or WhatsApp-only
    • Website not on the allowlist, or newly registered
    • Phone reused across unrelated brands
    • Name stuffed with “helpline”, “refund”, “24/7”
    • Pin location with no real office (ticket “box office” in a car park)
    MAP UAE-ground pins, green verified / red flagged, dotted lines between listings sharing a number24H MVP live Places API checks for 5 brands, 3 emirates
    SENSOR 2

    Lookalike Radar (brands + events)

    رادار النطاقات المشابهة

    Catches

    • Typosquats: emlratesnbd, adcbb, tamn
    • Homoglyphs: l ↔ I ↔ 1, rn → m, vv → w, Cyrillic а for Latin a (shows as xn--…)
    • Combosquats: tamm-fines-pay, abudhabigp-tickets, umrah-visa-2027
    • TLD swaps and subdomain tricks: adcb.com-verify.top

    How it works

    1. Each watchlist item generates candidates (dnstwist-style permutations + our UAE lure dictionary).
    2. Lure words are added in transliterated form too: naukri, trabaho, joli, velai.
    3. Resolve DNS / check registration for every candidate; live ones go to the analyser.
    4. Events carry dates, so the radar starts weeks before and tightens near the day.

    The + button

    • Add a brand: name, official domains, official phones, logo, languages
    • Add an event or holiday: name, dates, lure type (tickets, gifts, visas, packages)
    • Add a recruiter or agency: licence number, official site
    • Seeds regenerate instantly. Try it in the console above.
    MAP violet arcs from hosting location to the impersonated UAE brand24H MVP generator + DNS/RDAP checks for 10 brands and 3 events
    SENSOR 3

    Newborn Domain Sentinel (CT + WHOIS)

    رصد النطاقات حديثة الولادة

    Catches

    • Phishing domains within minutes of getting a TLS certificate, often before the first SMS goes out
    • Domains not in our candidate list but containing a brand or lure word

    How it works

    1. Stream Certificate Transparency logs (self-hosted certstream-server-go, or poll crt.sh for each watch term).
    2. Add daily newly-registered-domain lists as a second feed.
    3. Fuzzy-match every new name against all watchlists (edit distance, homoglyph skeleton, keyword hit).
    4. For hits: RDAP/WHOIS age, registrar, nameservers, IP/ASN, screenshot with Playwright.

    Signals

    • Age under 30 days, cheap TLD (.top, .xyz, .shop, .cc)
    • Page looks like the official site (screenshot pHash + logo match)
    • Form asks for card number, CVV, OTP or Emirates ID
    • Privacy-protected WHOIS + registrar often seen in past cases
    MAP amber pulse when a domain is “born”, with its age in hours24H MVP live CT stream filtered on UAE watch terms, shown on the map during the demo
    SENSOR 4

    Ads & Search Inspector

    فاحص الإعلانات ونتائج البحث

    Catches

    • Sponsored results and social ads that impersonate a brand or official body
    • Too-good offers: F1 VIP pass for AED 99, “refund of your fine”, discounted Umrah
    • Organic search results pointing to lookalikes (the part of the brief nobody else covers)

    How it works

    1. Search sweep: run lure queries per brand in every language through a SERP API, from a UAE location (“دفع مخالفات”, “pay fines Abu Dhabi”, “Dubai naukri visa”).
    2. Ad check: look up the advertiser in Google Ads Transparency Center and Meta Ad Library; or an analyst pastes an ad screenshot / link.
    3. Vision LLM reads the ad: brand, offer, price, landing URL, language.
    4. Follow the redirect chain twice, as a desktop bot and as a UAE mobile user. Different pages = cloaking.

    Signals

    • Advertiser page is new, renamed, or not the brand
    • Landing domain not official and/or under 30 days old
    • Price far below official price for that event
    • Cloaking, urgency text, card/OTP form on landing
    • Uses an official logo or a public figure’s face
    MAP pink pins at landing-page hosting; the case file shows the ad text in its original language24H MVP SERP sweep for 3 lure queries × 4 languages + paste-an-ad analyser
    SENSOR 5

    Kit Fingerprint & Actor Graph

    بصمة أدوات الاحتيال

    Catches

    • The operation behind many sites: same phishing kit, same operator
    • How many domains one actor runs, which brands, which languages, since when

    Fingerprints collected per site

    • Favicon hash (mmh3), DOM-structure hash, JS/CSS file hashes
    • Telegram bot token / chat ID used to exfiltrate card data
    • Google Analytics / Tag Manager IDs, tracking pixels
    • IP, ASN, nameservers, TLS cert SANs, JARM
    • Phone numbers and WhatsApp links (shared with Sensor 1 and 6)

    What police get

    1. Union sites that share rare fingerprints into one actor.
    2. Actor card: domain count, brands hit, hosting, first/last seen, languages.
    3. Strike pack: screenshots, WHOIS, DNS, hashes, timeline, LLM summary in AR/EN, and pre-filled abuse reports for registrar, host, Cloudflare, Google Safe Browsing, Meta, TDRA/aeCERT.
    4. A human approves every takedown.
    MAP red constellation lines between all sites of one actor24H MVP favicon + IP/NS + DOM hash clustering with a strike-pack PDF/JSON export
    SENSOR 6

    Job & Visa Scam Linguist

    رصد احتيال الوظائف والتأشيرات

    Catches

    • “Visa free” job offers that ask for fees, fake offer letters, fake recruiters using big-employer names
    • Fake domestic-worker and visit-to-work visa offers
    • The same lure posted in eight languages by one actor

    How it works

    1. Collect public posts: job boards, public Telegram channels, public Facebook pages/groups, search results in each language.
    2. Identify language and script, including Roman Urdu / Hinglish (fastText + LLM).
    3. Extract: employer named, fee asked, salary, contact, visa type.
    4. Cross-check recruiter against the MOHRE licensed-agency list and the employer’s real careers domain.
    5. Explain the verdict to police in AR/EN and to the public in the victim’s own language.

    Signals

    • Worker asked to pay for visa or recruitment (UAE law puts recruitment costs on the employer)
    • “Free visa”, “visit visa to work”, “no interview”
    • WhatsApp or Gmail only, no company domain
    • Salary far above the market for the role
    • Offer letter with copied ministry logos

    Four things the layer does

    • Seeds: for each watchlist item, the LLM produces lure keywords in every chosen language and their Latin transliterations (scammers put naukri, trabaho, joli in domain names).
    • Detects: language + script ID, including code-mixed Roman Urdu and Hinglish.
    • Normalises: Urdu/Persian/Arabic digits (۵۰۰ / ٥٠٠ / 500) and cross-script homoglyphs to one skeleton before matching.
    • Explains: evidence summary in Arabic and English for police; public warning in the victim’s language.

    08 · Extra ideas

    Additions that make the story stronger

    One number, many masks

    A phone-number graph across all sensors. The same WhatsApp number on a fake Aramex listing, a Tagalog job post and an ad landing page is the fastest way to tie an actor together.

    Pre-event defence list

    Two weeks before an event, give the brand owner the top unregistered lookalikes so they can register or block them before scammers do.

    Takedown clock

    Track time from detection to takedown per registrar and host. It shows the police where to push, and gives a strong metric for the pitch.

    Citizen checker (optional)

    A small WhatsApp-style checker that answers in 12 languages. It reads from the same database, so every public report also feeds the police map.

    Tourist scams

    Fake hotel bookings, desert safaris and event tickets aimed at Russian and Chinese speakers. Same sensors, different language seeds.

    Command-bar hunt

    Typing an entity name runs every sensor for it at once. This is the live demo moment: the judges name a company, RASID finds its fakes.

    10 · The demo

    Let the judges name the target

    Live demo, about 3 minutes

    1. Open the console. CT stream already running, the map is moving.
    2. Ask a judge to name a company or event. Type it into the command bar.
    3. RASID generates lookalikes in several languages and shows which are live.
    4. Open the worst one: screenshot, WHOIS age, card form, score, explanation in Arabic and English.
    5. Show its actor: 14 more domains on the same kit. Export the strike pack.
    6. Switch to UAE ground: a fake “customer care” Maps listing shares the same phone number.
    7. Filter by Malayalam: the job-visa corridor from Kerala lights up.

    • 0:00 The problem in one line, on camera (AR + EN subtitles)
    • 0:10 Type a brand, lookalikes appear

    Screen recording plus your own faces and voices. No AI-generated video.

    Risks to handle

    • False positives: official allowlists first, human approval before any takedown.
    • API terms: use Places and ad libraries through their official APIs; respect caching rules. The Meta Ad Library API has limited coverage outside the EU, so plan the paste-an-ad path.
    • Safety: never submit data into scam forms. Analyse pages read-only from an isolated browser.
    • Demo risk: cache a known-good run in case the venue Wi-Fi drops.
